# whatsapp-attendance-bot
Bot de atendimento automático para WhatsApp desenvolvido em Python com Flask, Twilio Messaging API e ngrok.
🚀 Automação de Atendimento no WhatsApp com Python & FlaskDesenvolvi um bot de autoatendimento para WhatsApp focado em agilizar o contato inicial com clientes, responder dúvidas frequentes e direcionar demandas de agendamento de forma automática.  A aplicação foi construída em Python utilizando Flask como backend para processamento de requisições HTTP. A integração de mensageria em tempo real é feita por meio da API da Twilio, que consome as respostas estruturadas via TwiML. Para o ambiente de desenvolvimento e testes locais, utilizei o ngrok para expor os endpoints locais com segurança via webhook.  Principais destaques do projeto:Menu Interativo: Reconhecimento de gatilhos textuais e navegação por opções dinâmicas.  Webhook Assíncrono: Recepção e resposta de dados no formato de mensageria instantânea.
